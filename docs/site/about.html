平台介绍

AiProxy 为不同模型提供统一的访问入口，支持对话、推理、代码辅助及图像生成等应用场景。开发者可以通过 API 将模型能力集成到产品中，也可以在兼容的开发工具和 AI 客户端中配置使用。

平台将模型选择、令牌管理、调用记录和账户用量集中在同一控制台，方便用户完成接入、调试与日常管理。

服务内容

模型接入
提供多种模型及对应接口。模型广场展示当前可用模型、支持能力和计费信息，便于根据业务需要选择。
访问管理
通过 API 令牌配置模型访问，为不同应用分别管理调用凭据与使用限制。
用量查询
支持查看调用日志、Token 用量及消费记录，用于接口调试、使用核对与日常管理。

接入与使用

接入前，请确认所选模型的接口协议、功能支持与价格，并按照产品文档配置接口地址和 API 令牌。建议先进行少量测试，再接入正式业务。

不同模型和客户端的兼容程度可能存在差异，实际能力与可用性以平台当前配置为准。API 令牌请妥善保管，不要公开或分享给他人。
