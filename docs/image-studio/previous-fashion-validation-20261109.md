# 服装模特工作室（2026-11-09 本地重做）

## 产品范围

按用户最新要求，主入口聚焦服装电商模特摄影。此前人物、商品、海报并列的通用创作页已撤下，三个面板的「资源／画布／助手」切换不再作为产品主线。旧快速生图入口保留。

核心流程：选择人物（可选）＋服装（必选）＋姿势（必选）→ 身形／取景／场景 → 预览方案 → 用户确认 → 生成结果 → 对比原参考 → 保留人物与服装、更换姿势再拍摄。

## 交互与参考工程的关系

重新实际走查 Open Pose & Costume 的工作台、素材选择弹窗与结果区。采用其清晰的交互组织：左侧稳定展示本次搭配，右侧稳定展示结果；点击参考位打开图库，选中后立即关闭并更新对应位置。用户不必先写提示词或操作独立助手。

没有复制参考项目素材、目录数据或 UI 源码。本地 UI 使用本站 Dialog、Button、NativeSelect、ModelSelector、StudioParameters、StudioCostEstimate、StudioAgentSettings、StudioPreview、ImageArtwork、ImageActions 和 GenerationProgress。新增业务组件解决已有组件未覆盖的职责选择、拍摄规格和参考对照。

新增电商导向能力：

- 真人身份参考独立于衣服和姿势；服装可上传平铺、人台或上身照片。
- 身形、成年身高观感、全身／七分身／半身和电商白底／自然生活／时尚棚拍均进入真实提示词。可选场景参考优先控制背景。
- 默认方案由所选素材和结构化选项编译，不产生分析费用；用户可以自选已配置视觉助手优化，分析单独计费。两种方式都必须确认后才执行生图。
- 生成前同屏复核参考图、身形、取景、画面质感、模型、数量、尺寸和费用。
- 原图下载、并排对照、叠加透明度、参考切换、历史版本和「保留搭配，换个姿势」。
- 已存拍摄可恢复素材与拍摄规格；「我的上传素材」从本人已存拍摄中检索，可跨拍摄复用。存储仅在当前浏览器，不宣称云素材库。

## 数据与请求

`use-portrait-elements.ts` 将选中元素变成真正的 File 参考图，替换同一职责时不累加图片；保持未修改参考图的对象 URL。下载失败保持原选项。下载期间禁用确认，防止旧参考提交；新拍摄／账号变化取消未完成选择。

`fashion-shoot.ts` 是可测试的结构化拍摄指令；`portrait-elements.ts` 提供原创目录、职责说明。方案快照包含描述、拍摄规格、模型参数和参考图身份／顺序／职责。修改任一输入后必须重新预览方案。沿用一次性提交锁、原生任务持久化、鉴权和计费，不自动重放未知结果的付费请求。

分析接口为 `POST /api/image-playground/plan`。仍使用所配置提示词助手的正常渠道与计费；仅接收有边界的 JPEG/PNG 预览，不抓取用户 URL、不执行模型描述的工具。实际生图传入原参考文件。

项目按用户隔离保存在 IndexedDB。上传素材随项目保存，清缓存后无法恢复。服务端结果仍保留 10 小时，本地图片历史最多 30 条；请下载重要原图。
