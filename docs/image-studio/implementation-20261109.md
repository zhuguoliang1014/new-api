# 通用创作工作台（2026-11-09，双模式交互重设计）

## 当前产品：自由生图与人物搭配

用户认可新的产品结构：同一个「创作工作台」提供「自由生图 / 人物搭配」两个选项卡，共用本站模型、收费、作品和历史。取消固定三步流程条，生成结果和版本对比仍沿用现有能力。

- **自由生图**：描述为主，可选上传图片，参考图均按普通编辑参考处理。支持拖放、粘贴、移除、PNG/JPEG/WebP及原有模型参考数量限制。不展示服装／姿势槽位或人物设置。
- **人物搭配**：人物／服装／姿势三个固定图片槽位。选中原图直接替换槽位预览；人物可上传或从库选择，服装与姿势仅从原项目库选择。下方为观察角度、可选补充描述及折叠的人物设置。旧项目中的其他参考仍显示并允许移除。
- **结果区**：自由模式提供描述示例（点击只填描述，不生成）；人物模式先显示人物＋服装＋姿势的当前组合。生成后继续支持原图、GIF/SVG、多结果、版本、下载和并排／叠加对比。
- **模型与费用**：输入区下方共用模型及画面设置，默认仍为 `gpt-image-2.5-flare-basic`。模型来自实际 bootstrap，用户已有模型偏好保留；生成前显示费用、数量与尺寸。
- **直接生成**：点击「生成图片／生成搭配」直接提交一次请求，不再强制先打开方案弹窗。两条路径都验证模型可用性、参数、参考数量、模型能力、Midjourney提示词长度与并发上限。同步锁与提交前作品ID快照防止重复点击及模式往返重放，完成后可再次明确生成。失败保留草稿，需先点击重新检查，再明确生成；从不自动重放付费请求。
- **可选助手**：AI创作助手打开可编辑方案，优化需另行点击，并标注分析独立计费。优化后仍明确确认生成；普通单步流程不调用分析模型。
- **两份草稿**：两个模式各有项目ID、描述、参考、人物设置和方案。切换前保存当前项目，仅重建目标模式文件的预览URL，旧URL释放，不静默丢弃输入；图片模型与参数共用。刷新后的旧项目通过「已存项目」恢复，对应模式自动恢复。浏览器持久化按账号隔离，模式之间不自动传递人物／姿势素材。

本轮基于项目现有 Tabs、Button、Dialog、StudioReferences、模型选择、任务和原图组件组合，没有增加依赖或新后端接口。`StudioReferences` 补充可选 disabled 属性以避免提交时误改参考，旧调用默认行为保留。
