# 创作工作台发布说明（2026-11-10）

工作台提供自由生图和人物搭配两个模式，共用本站模型、计费、历史及下载。模型显示易读名称，API选路与价格标识保持原值。画面参数在模型下方常显，AI创作助手为可选步骤，生成不自动付费重试。

## 本站素材

服务端目录 `controller/resources/studio-local-catalog.json`，当前288组姿势／1439个视角、1407套服装和1499个人物参考。六个已有场景单独保留。所有目录中的PNG原图与WebP预览／缩略图均使用本站 `/api/image-playground/assets/20261110/…`，不使用第三方图片地址。不补造下载包中没有的视角或深度图。

生产文件位于宿主 `/root/new-api/data/image-studio-assets/20261110/`，容器 `/data/image-studio-assets/20261110/`，不打入Git或镜像。旧图片不覆盖，新版本通过URL版本区分。客户端选择素材时读取原图，不用缩略图生成；PNG字节与本地提供文件逐张SHA-256一致。

默认资源根目录为进程工作目录的 `image-studio-assets/`，可用 `IMAGE_STUDIO_ASSET_DIR` 覆盖。公开接口仅提供明确版本、类型、目录和图片名，不能访问用户作品、任意URL或路径；静态资源不占用管理API限流预算。

## 使用日志

进入「审计日志」，分类选「创作工作台」。

- 打开工作台、选择模式、浏览素材库、选用素材、打开助手：登录用户的客户端交互；不代表图片已生成。
- 创作请求已接收：服务端队列实际接受新任务，同ID重放不重复记接单。
- 创作图片已就绪／生成失败／下载失败：服务端任务执行结果，含任务ID、模式、模型、参考数量、返回张数，可与原消费日志核对。

事件不记录提示词、用户文件名、图片、图片地址或Key。交互事件每用户最多60条／分钟，不阻塞生成，日志失败不触发重放。可按用户名及日期筛选；运维验收账号的事件不要当作真实用户使用。

按北京时间统计最近7天触达与实际生成，可在生产日志库只读执行：

```sql
SELECT (to_timestamp(created_at) AT TIME ZONE 'Asia/Shanghai')::date AS day,
       action, count(*) AS events, count(DISTINCT user_id) AS users
FROM audit_logs
WHERE category = 'image_studio'
  AND created_at >= extract(epoch FROM now() - interval '7 days')
GROUP BY day, action ORDER BY day, action;
```

要看真实普通用户，可追加 `AND actor_role = 1`；再按用户排除明确的测试账号。不要只看进入页面次数判断付费生成或收入。

## 发布恢复

受限备份和验证材料 `/root/upgrade-recovery/new-api-studio-20261110/`。应用回退脚本按已发布revision、Compose和环境文件校验，只切旧应用；保留当前用户、余额、订单、日志与素材文件，不整库恢复。
