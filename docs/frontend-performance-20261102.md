# 前端加载优化记录 · 2026-11-02

本次改动已在本地完成并验证，按用户要求纳入本地 `main`；未 push 或部署。仅修改前端资源加载及兼容性，未修改线上配置、数据库、权限或计费逻辑。

按用户要求，运行时只提供简体中文 `zhCN` 和英文 `en`。七语言源文件仍保留用于上游同步及历史数据测试，但其他五种语言不再进入应用构建。繁体中文浏览器和旧偏好统一为简体中文，其他已移除语言回退英文；菜单、个人偏好、登录偏好及日期控件遵循相同规则。

构建入口按同一 gzip 6 算法比较，MB 使用十进制。页面加载量来自浏览器 `encodedBodySize`，包括对应页面的异步 JS/CSS。整体构建目录包含未访问页面及图标库，不能当作每次打开页面的下载量。

主要改动：

- 中英文语言包独立分块缓存，小范围业务更新不再要求重新下载翻译包。
- 设置路由校验、侧栏导航只引用轻量 `section-navigation.ts`。设置表单和编辑器随对应页面加载；各设置区的地址、标签、默认页和内容关联保留。
- UI 与 TanStack 的固定公共分块只提取首屏使用的模块，避免将异步页面的控件、表格依赖一起提升至首屏。
- 首页 Cherry Studio 图标直接导入选用的 SVG 组件，避免品牌总入口附带的组件依赖。
- Markdown 和数学公式渲染器按内容模式加载。价格列表、模型详情、性能图表、API 代码示例分别加载，未打开的详情和标签不预先下载大型依赖。
- 画图默认尺寸选择改用普通反向循环，保持原有最高分辨率选择行为，支持没有 `Array.findLast` 的浏览器，并消除现有 ES2022 类型检查错误。
- `bun run build` 增加全部首屏 JS/CSS 的 gzip 650 KiB 预算；原始构建会超限，当前构建通过。

验证采用本地生产构建和独立 HTTP 测试服务。浏览器网络模拟为 500,000 字节/秒、100 ms 延迟、CPU 4 倍降速、禁用缓存。公开状态使用只读快照；首页使用默认首页，价格页使用空目录以隔离资源加载成本；品牌图使用相同的本地图，关闭了测试环境的第三方人机验证。数据不包含生产 API 等待、真实账号登录、线上品牌原图以及完整价格目录的绘制开销，不作为生产提速承诺。

- TypeScript 6.0.3 类型检查、涉及文件的 oxlint / oxfmt 检查、生产构建与首屏预算检查通过；七语言源文件同步脚本通过，未修改翻译 JSON。
